# iPhone to Drive Upload Workflow

## Quick Start
1. Open Google Drive app on your iPhone
2. Navigate to `Tyler_Editor_Hub` → `2_RAW_FOOTAGE` → `[Brand Name]`
3. Choose folder: `voiceovers/` or `brolls/`
4. Tap `+` button → `Upload`
5. Select video from Photos
6. Wait for upload to complete

## Detailed Steps

### From Google Drive App
- Tap folder icon → navigate to brand folder
- Open `voiceovers/` or `brolls/` subfolder
- Tap `+` (bottom right)
- Select `Upload`
- Choose video from Camera Roll
- Name appears automatically; rename if needed
- Tap upload arrow to confirm

### File Naming Convention
Use this format so Mary knows what she's working with:
`[Brand]_[Date]_[Format]`

Examples:
- `Phrasly_050326_voiceover.mp4`
- `Kalshi_050326_broll.mov`

### Which Folder?
- **voiceovers/** = You talking on camera, your voice, talking head content
- **brolls/** = B-roll clips, background footage, product shots, no voice

## Desktop Upload (Faster for Large Files)
1. Go to drive.google.com
2. Navigate to Tyler_Editor_Hub → 2_RAW_FOOTAGE → [Brand] → voiceovers or brolls
3. Drag and drop video files into folder
4. Much faster than iPhone app for multiple files

## Troubleshooting
- Video won't upload? Check file size (Drive has limits on very large files)
- Takes too long? Use desktop for videos over 500MB
- Can't find folder? Make sure you're in Tyler_Editor_Hub first
